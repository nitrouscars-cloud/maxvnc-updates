# MaxVNC — mises à jour

Fichiers lus par « Rechercher une mise à jour… » dans MaxVNC Server, MaxVNC Viewer (Windows) et MaxVNC Viewer (Android).

- `latest.json` : dernière version, signé par `latest.json.sig` (Ed25519).
- `windows/<version>/` : installateur et exécutables Windows x64 (Server, Viewer).
- `android/<version>/` : APK Android.

Chaque version a son propre dossier : le cache de GitHub ne peut pas servir un ancien fichier sous la même adresse.
